## How I work

I build with AI-assisted tooling day to day — **Claude Code** and **Cursor** are
part of my normal workflow, not an experiment. In practice that means faster
iteration on the boring parts and more of my attention on the things that
actually decide whether a system holds up: data modelling, edge cases,
money-handling correctness and failure behaviour.
